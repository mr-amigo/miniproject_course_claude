# miniproject_course_claude

Міні-проєкт №2 | ООП
Пройдений курс: Claude Code in Action від claudecertifications.com

## Що тут є

`CLAUDE.md` згенерований командою `/init` файл з контекстом проєкту для Claude Code, щоб модель краще орієнтувалась у репо.

`CERTIFICATE.pdf` підтвердження проходження курсу, пройдено фінальний квіз.

`analyze.py` Python-скрипт, який демонструє роботу з Claude Code SDK. Через subprocess викликає команду `claude -p` (print mode без інтерактиву) з промптом проаналізувати код у папці `todo/` і зберігає відповідь у файл `analyze_result.md` з timestamp. Запускається командою `python3 analyze.py`.

`.mcp.json` конфіг для підключення filesystem MCP сервера, який додає Claude можливість працювати з файлами через стандартизований Model Context Protocol.

`.github/workflows/review.yml` GitHub Action, який запускається на кожен pull request у main, ставить Python 3.11 і виводить поточний стан задач todo у логи. Простий приклад інтеграції з GitHub без офіційного Anthropic action (потребує API-ключ).

## modules/

Папка з конспектами по курсу. Курс складається з 14 відеоуроків і фінального квіза, поділених на 4 модулі. Структура папки повторює структуру курсу: кожен модуль це окрема піддиректорія, кожен урок всередині модуля теж окрема піддиректорія. У кожній лежить `my_conclusions.txt` з моїми ключовими висновками з уроку.

## todo/

Пет-проект для практики, який створювався і поступово розширювався протягом курсу. Це простий CLI трекер задач на чистому Python без зовнішніх залежностей. Зберігає задачі у JSON, підтримує додавання, перегляд, виконання, видалення, поле пріоритету (low/medium/high) і сортування. Кожна нова фіча Claude Code тестувалась на цьому проєкті: planning mode для додавання пріоритетів, custom commands для шорткатів, hooks для логування правок, SDK для автоаналізу.

Приклад використання:

```bash
python3 -m todo add "купити каву" --priority high
python3 -m todo list
python3 -m todo done 1
```

## .claude/

Папка з конфігами Claude Code для цього проєкту.

`settings.json` містить 5 активних хуків. `SessionStart`, `UserPromptSubmit`, `SessionEnd` працюють разом і записують усі мої промпти до Claude Code у файл `prompts.md`. `PostToolUse` логує кожне редагування файла у `edits.md`. `PreToolUse` блокує доступ до `.env` файлів через matcher Read|Grep і Bash, повертаючи exit code 2 з повідомленням про блокування.

`commands/` містить три кастомні слеш-команди для Claude Code. Це markdown файли, де ім'я файла стає командою, а вміст це промпт який Claude виконує. `/run` запускає `python3 -m todo list`, `/add-task` додає задачу з high пріоритетом, `/done-task` позначає виконаною.

`prompts.md` повний журнал усіх моїх промптів до Claude Code за весь час проходження курсу. Згенерований автоматично хуками SessionStart/UserPromptSubmit/SessionEnd: коли стартує сесія Claude Code, хук дописує заголовок з timestamp і session-id, потім кожен мій промпт автоматично дописується у файл як цитата. Цей механізм я налаштував для того, щоб показати як реально відбувалося проходження курсу і можливість потім переглянути власну хронологію роботи(вважаю що під проходження такого типу курсу - це доволі доречно як і для мене, так і для показу роботи яку я проробив)
